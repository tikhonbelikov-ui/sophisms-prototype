# UI/UX аудит: Expo Native UI + Expo Design System

Проверка по требованиям официальных Expo Skills (expo-overview, expo-native-ui, expo-design-system) и рекомендациям Android Accessibility. Это **проверка исходников и токенов**, не полноценный визуальный тест на устройстве.

| Критерий | Статус | Что сделано / что проверить |
|---|---|---|
| Единая цветовая система | В коде: выполнено | `theme.js`: game/read. В прежнем коде фиолетовые поля, серые кнопки и тёмно-синий фон конкурировали. |
| Тёплая библиотека и холодная игра | Выполнено | Отдельные семантические палитры, единые отступы и радиусы. |
| Чёткость домашнего экрана | Выполнено по коду | Весь фон — непрозрачный, без `ImageBackground`/blur и старой растровой подложки. На устройстве нужно проверить композицию на 320–360dp. |
| Системные диалоги | Выполнено по коду | Не используются `Alert.alert` и `Modal`; in-app overlay внутри SafeAreaView. |
| Контраст | Проверено автоматическим расчётом | Основной текст: 10.6–12.8:1 на основных поверхностях. Вторичный текст на фоне 5.0–5.9:1. Текст акцента 5.0–6.7:1. Это соответствует AA для обычного текста. |
| Размер текста | В основном выполнено | Основной текст 16, вспомогательный 14, заголовки 25–34; label 13 только для коротких uppercase-подписей. Динамическое увеличение не заблокировано, но требует теста на устройстве. |
| Размеры касаний | Частично | Action/Chip/Back 48dp и выше, поля от 50dp. Нужно проверить текстовые ссылки и крупный системный шрифт на устройстве. |
| Доступность | Частично | accessibilityRole и selected/expanded на основных интерактивных элементах, понятные подписи. Полный тест TalkBack не пройден. |
| Обработка пустых состояний | В коде: выполнено | Нет результатов поиска, запрет игры при недостаточном количестве выбранных карт, сообщения при ошибках. |
| Сохранение партии | Реализовано, не проверено на устройстве | AsyncStorage, восстановление из локального JSON; возможны нюансы конкурентной записи при внезапном выключении. |
| Визуальная и UX консистентность | Частично | Общие компоненты Txt, Action, Chip, Panel, Accordion, Overlay. Нет старой смеси тёмно-фиолетовых/серых Material-поверхностей. |
| «Всё в карточках» | Частично | Составной раздел настроек использует панели; для каталога можно позже сделать плоские строки, если окажется слишком плотным. |
| Нагрузка | Частично проверено в 2.2 | Каталог использует индекс, статьи разбираются при открытии. 81 карточка на ScrollView; плавность на устройстве не измерена. |
| Мобильная сборка | Частично проверено в 2.2 | npm, Android prebuild и Android/Hermes export работают. Нативный APK и запуск не проверены: нет Android SDK. |
| Полнота / достоверность уроков | Перенос проверен / достоверность не проверена | Встроены 63 полных разбора и 991 вопрос. Текст перенесён без потерь. Факты требуют отдельной редакторской вычитки. |

## Следующие обязательные проверки перед распространением

1. Телефоны Android 320–360dp, 393dp и 430dp; экранная клавиатура в форме настроек и оверлеях.
2. Масштаб шрифта 150–200%, TalkBack, аппаратная кнопка «Назад», системная строка состояния и навигация жестами.
3. 20 минут работы таймера, сворачивание/возврат, завершение по 00:00, ошибка после исчерпания банка.
4. На телефоне: открытие 63 полных уроков, ссылки, тесты с ровно тремя вариантами. Импорт выполнен.
5. Установка поверх старого APK: package id, versionCode и идентичный ключ подписи.

## Палитры

- Game: `#EDF5FB` (фон), `#FFFFFF` (поверхности), `#285E94` (акцент), `#17344F` (текст).
- Reading: `#FAF3E7`, `#FFF9EE`, `#985E2B`, `#3C2C21`.

*Оценка качества:* статическая проверка достаточна для ревью исходников и демонстрации тем, но **недостаточна**, чтобы утверждать, что готовый интерфейс идеально выглядит/работает на реальном Android.

## Раздел «Тесты», версия 2.3

Тёплая палитра полностью переиспользует тему read. Выбор вариантов — radio с checked/disabled; правильность помечается текстом, а не только цветом. Кнопки 48–64 dp и выше. Витрина и история используют FlatList; вопросы и разбор ошибок прокручиваются. Прогресс сохраняется после каждого проверенного ответа; UI подтверждает сохранение только после успешной записи.

Figma: попытка записи заблокирована лимитом MCP Starter. Подготовлен локальный редактируемый HTML-макет трёх состояний с PNG-превью. Визуальная проверка браузерной версии не заменяет Android/TalkBack/системный шрифт на телефоне.
