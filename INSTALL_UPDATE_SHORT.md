# Софизмы 2.4 — установка и обновление на Windows / Android

Архив содержит **полный проект с 63 уроками и тестами**, но **не готовый подписанный APK**. Старый проект, установленное на телефоне приложение и ключ подписи пока не удаляйте.

1. Распакуйте `Sophisms_Release_2_4_EDITORIAL.zip` в **новую папку** (например, `C:\Users\igcomp\sp\Sophisms_2_4`). Откройте PowerShell в папке, где лежит `package.json`.
2. Запустите команды:

```powershell
npm.cmd ci
npm.cmd run test:logic
npm.cmd run check:syntax
```

`npm.cmd ci` устанавливает точные версии зависимостей из `package-lock.json` (при первой установке нужен интернет). `npm.cmd run test:logic` запускает автоматические проверки данных и игры. `npm.cmd run check:syntax` проверяет синтаксис JSX. Не продолжайте сборку при ошибках.

3. В Android Studio выберите **Open → `...\Sophisms_2_4\android`**, дождитесь Gradle Sync. Папка Android уже включена, `expo prebuild` не нужен. При запросе SDK установите недостающие платформы в SDK Manager.
4. В меню **Build → Generate Signed App Bundle or APK → APK** выберите модуль `app`, конфигурацию `release` и **тот же keystore, alias и пароли, которыми подписана установленная на телефоне версия**. Если подписанного APK ещё не было, используйте новый постоянный релизный ключ и храните его отдельно.
5. Передайте собранный APK на телефон и откройте. Если сертификат и пакет совпадают, Android предложит **обновить существующее приложение**, сохранив локальные данные. **Не удаляйте старое приложение для обновления.**

**Идентификатор пакета:** `com.sophisms.prototype`. **Версия:** `2.4.0`. **versionCode:** `7` (предыдущий архив 2.3 использовал `6`). Если установленная версия имеет код `7` или выше, увеличьте номер **в обоих файлах** `app.json` и `android/app/build.gradle` перед сборкой. Иначе Android не установит новую сборку поверх прежней.

В конце проверьте навигацию «Играть — Правила — Читать — Тесты», сворачивание длинных уроков, 33 определения, SOF-005/012/046/053, офлайн-тесты и сохранённые результаты.

Более подробная пошаговая инструкция по Android Studio, JDK, SDK, подписи и восстановлению ошибок — в `BUILD_APK_WINDOWS.md`.
