# Мания заблуждений — прототип

Небольшое мобильное приложение на React Native и Expo для игры с софизмами на одном телефоне. В текущей версии участвуют **один спорщик и один отгадчик**. Приложение выдаёт спорщику тайную карточку, а отгадчик пытается распознать приём в живом разговоре.

## Что уже работает

- Главный экран с разделами **«Играть»**, **«Читать»** и **«Правила игры»**.
- Создание партии: можно указать имена двух игроков.
- Передача телефона спорщику и показ его тайной карточки.
- Каталог из четырёх софизмов с краткими объяснениями и примерами.
- Выбор карточки отгадчиком, подтверждение попытки и сообщение о результате.
- После правильной догадки спорщику выдаётся следующая карта; после четырёх карт можно начать новую партию.

Софизмы сейчас хранятся прямо в коде. Подсчёта очков, аккаунтов, игры по сети и сохранения партии нет. Реплики игроков приложение не распознаёт: отгадчик сам выбирает карточку после разговора.

## Где что находится

```text
SophismsPrototype/
├── App.js               # Экраны, оформление и действия пользователя
├── game.js              # Четыре карточки и правила выдачи/проверки карт
├── index.js             # Точка входа: регистрация главного компонента приложения
├── app.json             # Настройки Expo: название, версия, Android package
├── package.json         # Зависимости и команды проекта
├── package-lock.json    # Зафиксированные версии npm-зависимостей
├── assets/              # Иконки и изображения для приложения
├── .gitignore           # Файлы и папки, которые Git не загружает
└── README.md            # Это описание
```

**Основной код приложения** находится в `App.js` и `game.js`. В `App.js` реализованы переходы между экранами, ввод имён, показ карт и обработка попытки. В `game.js` находятся данные карточек и функции `createGame`, `getCard`, `isCorrectGuess` и `replaceGuessedCard`. `index.js` запускает компонент `App`.

Папка `assets/` содержит изображения для иконки и экрана загрузки. `app.json` задаёт отображаемое имя «Мания заблуждений» и идентификатор Android-приложения `com.sophisms.prototype`.

## Как запустить проект

Понадобятся Node.js, npm и приложение Expo Go на телефоне. После получения доступа к репозиторию выполните в PowerShell:

```powershell
git clone https://github.com/tikhonbelikov-ui/sophisms-prototype.git
cd .\sophisms-prototype
npm.cmd ci
npx.cmd expo start
```

Откройте проект в Expo Go с помощью QR-кода из терминала. Компьютер и телефон обычно должны находиться в одной сети Wi-Fi. Если локальное соединение не работает, попробуйте `npx.cmd expo start --tunnel`.

Использование `npm.cmd` и `npx.cmd` в Windows PowerShell помогает обойти ошибку, при которой запуск скриптов `npm.ps1` или `npx.ps1` запрещён политикой PowerShell.

## Как получить APK

Для локальной сборки Android нужны Android Studio, Android SDK и совместимая с проектом Java. Сначала установите зависимости через `npm.cmd ci`, затем создайте папку нативного проекта командой:

```powershell
npx.cmd expo prebuild --platform android
```

Откройте созданную папку `android` в Android Studio, дождитесь синхронизации Gradle и воспользуйтесь меню **Build → Generate Signed Bundle / APK**. Для подписанной сборки потребуется файл ключа (`.jks`) и пароли к нему. Храните ключ и пароли отдельно от репозитория: без прежнего ключа нельзя выпустить обновление уже установленного приложения с той же подписью.

Папки `android/`, `ios/`, `node_modules/`, результаты сборки, APK и файлы ключей перечислены в `.gitignore`. Поэтому после клонирования зависимости нужно установить заново, а папку `android/` при необходимости сгенерировать. Исходный код игры при этом остаётся в репозитории.

## Статус

Это пробный прототип для проверки экранов и механики угадывания. Содержимое партий хранится только в памяти приложения и сбрасывается после его перезапуска.
