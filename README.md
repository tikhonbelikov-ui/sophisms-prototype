# Мания заблуждений — голубой интерфейс, несколько игроков и таймер

Это **пакет обновления исходников** для существующего репозитория
`https://github.com/tikhonbelikov-ui/sophisms-prototype`, а не готовый APK.

## Что изменилось

- Новый светлый интерфейс по правому набору экранов Figma: `https://www.figma.com/design/QpBJXac5lAIfyuPJsxU1nh`.
- Кнопки тёмно-синие `#274E93`, фиолетовые игровые карты, светлые поля ввода, закруглённые панели.
- Добавление и удаление участников (от 2 до 8), выбор спорщика / отгадчика; один игрок может иметь обе роли.
- Таймер раунда от **00:01 до 99:59**, по умолчанию **05:00**; кнопки паузы, продолжения и сброса.
- Таймер запускается после завершения тайной выдачи всем спорщикам. При необходимости скрытой повторной выдачи карты приостанавливается. При сворачивании приложения также ставится на паузу.
- Одновременно выданы разные карты каждому спорщику (максимум 4 спорщика, потому что в демонстрационной колоде 4 карты).
- Тайная карта раскрывается только тому, кому передали телефон; описание можно показать касанием.
- Замена карты исключает предыдущую из текущей партии.
- Отгадчик выбирает себя и конкретного спорщика перед проверкой. Ошибка не убирает карту; правильный ответ выдаёт новую карту при наличии.
- Предупреждение перед просмотром секретных карт и таблица итогов.
- В разделе «Библиотека» доступны четыре исходных софизма с примерами.

**Подсчёт очков:** 2 за верное угадывание, −1 за неверное, но итог не меньше нуля. Это демонстрационное правило; в исходном макете его формула не задана.

## Обновление уже имеющегося проекта на Windows 11

1. Сделайте резервную копию папки приложения. Не теряйте старый файл подписи `.jks`, пароли к нему и существующий файл `package-lock.json`.
2. Распакуйте архив в отдельную папку. **Скопируйте файлы и подпапки пакета поверх соответствующих файлов существующего проекта**. Существующие `package-lock.json`, `index.js`, `.gitignore` и прочие ресурсы не удаляйте.
3. Откройте PowerShell в корне проекта (там, где `App.js`).
4. Выполните:

```powershell
npm.cmd install
npm.cmd run test:logic
npx.cmd expo prebuild --platform android
```

5. Откройте папку `android` в Android Studio и дождитесь синхронизации Gradle. Проверьте в `android/app/build.gradle`, что `applicationId` остаётся `com.sophisms.prototype`, а `versionCode` равен **2** (или больше, чем у уже установленной сборки). Expo может не полностью перезаписывать вручную изменённый нативный проект.
6. Для проверки на подключённом устройстве или эмуляторе можно запустить:

```powershell
npx.cmd expo run:android
```

7. Для APK на устройство используйте в Android Studio **Build → Generate Signed Bundle / APK → APK** и подпишите **тем же `.jks`**, которым подписана предыдущая установленная версия. Для обновления поверх старой версии нужны и тот же `applicationId`, и та же подпись, и больший `versionCode`.

Если нужно собрать с нуля, сначала клонируйте первоначальный Git-репозиторий и только потом скопируйте эти обновлённые файлы. В этом архиве намеренно нет `package-lock.json`, `android/`, `node_modules/` и секретных файлов подписи.

### Ранее возникшие проблемы установки

- **PowerShell блокирует `npm.ps1`**: используйте `npm.cmd` / `npx.cmd`.
- **Java/Gradle**: для прежней сборки использовали JDK 17 из Android Studio (`.../Android Studio/jbr`); при ошибках проверьте `JAVA_HOME` и выбранный Gradle JDK в Android Studio.
- **Android SDK Platform 36 не найден**: установите нужную платформу в **Tools → SDK Manager → SDK Platforms**.
- **Старая нативная папка Android**: не запускайте `expo prebuild --clean` без резервной копии; команда может удалить локальные настройки подписи и другие ручные изменения.

## Проверка и ограничения

- Автотесты игровой логики и таймера выполнены: 8/8 успешно.
- JSX был проверен синтаксическим анализатором TypeScript.
- **APK не собирался**, работа на устройстве и подписание ещё не проверены. Не заявляется, что Gradle-сборка прошла.
- Внешние изображения и новые зависимости не требуются; интернет для игры не нужен.
- Фон `sky-clouds.png` локально восстановлен по визуальному образцу, **это не оригинальный файл облаков из Figma**. Остальные экраны сверены по макету и воспроизведены нативными элементами. Чтобы получить полностью попиксельный результат, замените PNG исходным облачным изображением из Figma и при желании добавьте исходный шрифт `Playfair Display SC`.
- Название, Android package и механизм подписи оставлены совместимыми с исходным проектом, но без исходного ключа подписи нельзя собрать устанавливаемое поверх прежнего подписанное обновление.
- Партия и счёт пока хранятся в памяти; при закрытии приложения они сбрасываются.
