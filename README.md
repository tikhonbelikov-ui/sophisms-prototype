## Сборка на Windows

Полная инструкция — BUILD_APK_WINDOWS.md рядом с этим файлом.

1. Распакуйте архив в НОВУЮ папку с коротким латинским путём. Корень проекта — папка с package.json. Старый проект и ключ подписи оставьте на месте.
2. Нужны Node.js 24 LTS (минимум 22.13), Android Studio, Android SDK 36.
3. В PowerShell из корня проекта выполните:

~~~powershell
npm.cmd ci
npm.cmd run test:logic
npm.cmd run check:syntax
~~~

4. В Android Studio: Open → вложенная папка android. Она уже подготовлена; expo prebuild для обычной сборки не нужен.
5. Дождитесь Gradle Sync. Затем Build → Generate Signed App Bundle or APK → APK.
6. Укажите существующий ключ, его alias и пароли; выберите release и соберите APK.
7. Нажмите Locate в уведомлении о завершении, перенесите APK на телефон и установите.

Для обновления установленного приложения нужен именно ключ, которым подписана установленная версия. Архив не содержит ваших личных ключей или паролей.

Первая сборка требует интернета для npm, Gradle и Android SDK. Само приложение и библиотека работают офлайн; подписанному release APK не нужны компьютер и Metro.

## Раздел «Тесты»

Отдельная вкладка в тёплой теме библиотеки: витрина 63 тем с поиском и фильтрами, прохождение с тремя ответами и пояснениями, история и разбор ошибок. В статье кнопка «Пройти тест по теме» открывает тот же раздел.

Каждый проверенный ответ сохраняется сразу. Его нельзя заменить или учесть дважды. Черновики разных тем хранятся независимо; можно выйти и продолжить после перезапуска. Завершение добавляет новую запись, не стирая прошлые попытки. Статистика показывает число завершённых прохождений, уникальных пройденных тем, лучший/последний результат и общий процент по всем ответам завершённых попыток. Учебные результаты не изменяют очки и банк ошибок настольной игры.

Результаты локальны для установки приложения, без учётных записей и облачной синхронизации. Сохраняются компактные индексы ответов, а не копии уроков. Очистка данных или удаление приложения может удалить прогресс. При ошибке записи ответ не выдаётся за сохранённый; его можно проверить повторно.

Макет трёх состояний находится в design/tests-mockup.html и design/tests-mockup.png. Это проектные примеры состояния, не статистика пользователя. Запись в Figma была заблокирована лимитом MCP Starter; исходный Figma-файл не изменён.

## Размер и загрузка

63 исходных TXT: 1 731 540 байт (~1,65 МиБ). Готовые JSON-статьи: около 1,9 МБ; актуальные размеры — в CONTENT_MANIFEST.json. Это небольшой объём по сравнению с React Native и нативными библиотеками APK.

Оригиналы в source_lessons нужны для редактирования; приложение не импортирует их в JavaScript-пакет. В APK включается одна используемая версия каждой полной статьи. ZIP и инструменты Android упаковывают данные; итоговый размер зависит от сборки и архитектур. Дополнительное ручное сжатие здесь не требуется.

## Проверки и ограничения

Проверены целостность исходников, перенос учебного текста без потери абзацев, вопросы и ключи, игровая логика, синтаксис JSX, создание Android-проекта, экспорт Android JavaScript/Hermes через Metro.

Подписанный APK здесь не собран: нет Android SDK и вашего ключа. Проверка на телефоне, TalkBack, крупный системный шрифт, прокрутка и клавиатура остаются проверками на устройстве. Экспорт JavaScript не заменяет нативную Gradle-сборку.

CONTENT_IMPORT_REPORT.md описывает особенности исходников. Полный фактчекинг всех исходных разборов не проводился; кампания Camel проверена по Stanford SRITA.

## Повторный импорт — только после изменения текстов

Нужен Python 3.10+:

~~~powershell
python .\tools\import_lessons.py
npm.cmd run test:logic
~~~

Для обычной сборки APK это не требуется.
